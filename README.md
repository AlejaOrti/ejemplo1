Proyecto desarrollado como parte de la formación en Desarrollo Frontend de Alura Latam, con el objetivo de aplicar conocimientos de HTML, CSS y diseño responsivo en la construcción de una página web moderna y funcional.

Este proyecto permitió poner en práctica conceptos fundamentales de maquetación web, organización de contenido, estilización de interfaces y adaptación a diferentes dispositivos, garantizando una experiencia de usuario consistente tanto en computadoras como en dispositivos móviles.
